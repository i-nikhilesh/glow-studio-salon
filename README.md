
# Glow Studio | Salon Website

## About the Project

Glow Studio is a fictional salon website created as a frontend development portfolio project.

The website features a premium brown-and-gold theme, responsive layouts, and a clean user interface designed to provide a professional browsing experience.

This project demonstrates my skills in HTML, CSS, responsive web design, and website deployment.

## Features

- Modern and elegant homepage
- Fully responsive layout
- Professional About section
- Salon services with pricing
- Attractive image gallery
- Contact information and Google Maps
- Professional footer with quick links
- WhatsApp booking placeholder
- Mobile-friendly navigation and layout

## Technologies Used

## How to Run Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html in your browser.
4. Alternatively, use the Live Server extension.

No additional installation is required.
